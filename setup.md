# Setup guide

Allow 45 to 60 minutes the first time, most of it spent on Google credentials.

## 1. Prepare the tracker

Create a Google Sheet with two tabs, named exactly:

- `Workstreams`
- `Risks and Decisions`

Paste in `samples/input/workstreams.csv` and `samples/input/risks_decisions.csv` (*File > Import > Insert new sheet(s)* works, then rename the tabs). Keep the header row exactly as in the samples. Column rules are in [data-contract.md](data-contract.md).

Replace the sample rows with real ones. Keep one or two rows of sample data until the first successful run so you can compare.

Copy the sheet ID from the URL: `https://docs.google.com/spreadsheets/d/`**`THIS_PART`**`/edit`.

## 2. Import the workflow

In n8n: *Workflows > Add workflow > Import from file*, then choose `workflow/weekly-ops-status.json`.

The workflow imports **inactive**. Leave it that way until step 6.

## 3. Create credentials

| Credential type | Used by | Notes |
|---|---|---|
| Google Sheets OAuth2 | Read Workstreams, Read Risks and Decisions | Needs read access to the tracker |
| Google Calendar OAuth2 | Read Calendar | Read access to the calendar you scan |
| Gmail OAuth2 | Email for Review | Send permission |
| Header Auth | AI Executive Summary | Name: `x-api-key`. Value: your Anthropic API key |
| Slack API (optional) | Slack Post | Only if you enable that node |

On self-hosted n8n, Google OAuth needs a Google Cloud project with the Sheets, Calendar and Gmail APIs enabled and an OAuth client whose redirect URL matches your n8n instance. n8n cloud provides a simpler connect flow.

Open each node that shows a red credential warning and select the credential you created.

## 4. Edit the Config node

Set at minimum:

- `sheetId`: from step 1
- `reviewRecipient`: your own email address

Check `workstreamsTab` and `risksTab` match your tab names exactly.

## 5. Test run

Open the workflow, click **Execute workflow** from the **Manual Run** trigger.

Expected: every node turns green and an email arrives. Compare against `samples/output/weekly_status.html`.

If a node fails, click it and read the error. Common causes are in the next section.

## 6. Activate

1. Switch the workflow to **Active**. The Monday 07:00 trigger uses the timezone in the workflow settings (default `Europe/Berlin`). Change it under *Workflow settings > Timezone*.
2. Keep `reviewRecipient` on yourself for the first two to three weeks.
3. Set an **Error workflow** under *Workflow settings* that emails you when a run fails. Silent failure is the main operational risk of any scheduled job.

## 7. Go to leadership

When the report has been correct three weeks running, change `reviewRecipient` to the leadership address or list. To also post to Slack, enable the **Slack Post (optional)** node, pick the channel and select the credential.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| Read Workstreams returns nothing | Tab name mismatch or wrong sheet ID | Check `Config`. Tab names are case-sensitive. |
| Report shows 0 workstreams | Header row renamed or missing | Restore headers exactly as in the data contract. |
| Everything shows "No status" | Status column holds values other than Green, Amber, Red | Use a dropdown (data validation) in the sheet. |
| Dates show as empty or never overdue | Dates stored as text like "5th Oct" | Use real date cells or `YYYY-MM-DD`. |
| Calendar section always empty | Keywords do not match your event titles | Edit `calendarKeywords` in `Config`. |
| Summary says "generated by rules" | AI call failed or node disabled | Open the AI node's last execution. Usual causes: wrong header name, expired key, model name. |
| Email arrives as raw HTML | Email type not HTML | Open Email for Review and set *Email Type* to HTML. |
| Warning icon on a connector node after import | Node parameters differ in your n8n version | Re-select the sheet, calendar or recipient in the node and save. |
| Nodes run several times | The `Execute Once` setting was lost on a read node | Open the node, *Settings*, switch **Execute Once** on. |
